# v0.5 research evidence

Generated by `scripts/build_v0_5_evidence.py` from the committed clean-run
outputs in `results/v0.5.0-release/` and `results/v0.5.0-null/`.

- `result_summary.json` -- headline numerators, Wilson intervals, fit failures,
  unique-seed count, null result, and SHA-256 hashes of raw inputs.
- `recovery_by_magnitude_timescale.csv` -- primary predeclared subgroup table,
  n=75 per `(magnitude, tE, endpoint)` row.
- `recovery_by_sampling.csv` -- descriptive cadence-support strata.
- `recovery_by_season_edge.csv` -- exploratory boundary-distance strata; small
  cells and no multiplicity correction make this hypothesis-generating only.
- `research-quality-rubric.json` -- the explicit evidence behind the requested
  before/after repository graph; an expert heuristic, not peer review.
- `blind-search-performance-benchmark.json` -- a same-input diagnostic of the
  proposal-stage optimization, with a warning against generalizing the bright-
  case speedup to difficult boundary fits.

The associated SVGs live in `results/figures/`. Every scientific number in the
README and manuscript traces to these files or the raw run directories.
