# Synthetic Point-Lens Microlensing Recovery Study: Post-audit protocol

**Author:** Biswajit Jana

**Status:** methods protocol; post-audit scientific results not yet claimed

## Abstract

We specify a synthetic point-lens injection/recovery experiment using an
explicit Roman-motivated observing-window proxy and a blind event search. The
work evaluates this software selection function only. It is not a Roman
readiness assessment, mission completeness measurement, population yield
forecast, or discovery claim.

## Methods

The default model is a uniform-source isolated point lens. An event epoch is
drawn within one of six declared seasons. Synthetic flux is sampled at the
configured cadence and perturbed by a phenomenological magnitude-dependent
noise model. A fixed timescale bank locates data-driven event candidates; each
candidate seeds the same bounded PSPL fit. Injected parameters never initialize
the search. The identical search is applied to constant-flux null realizations.

Threshold crossing and parameter recovery are distinct endpoints. Every trial
retains injected and fitted `t0`, `u0`, and `tE`, the detection statistic, seed,
and failure classification. Aggregates use Wilson binomial intervals.

## Results

No post-audit population or mission-level result is asserted. Earlier 58%
recovery and 0/200-null values were generated by a truth-seeded pipeline and
are superseded. New results require committed raw tables, configuration and
manifest, and independent review.

## Invalid planetary pathway

The repository's inverse-ray-shooting binary-lens implementation does not
converge to the required point-lens limit across the tested trajectory and has
an invalid zero-ray fallback. Scientific planetary runs are blocked in code.
Future work must compare against an independently maintained solver over a
predeclared validation suite before re-enabling that channel.

## Limitations

See `docs/LIMITATIONS.md`. In particular, the cadence and noise are scoped
proxies, and the null ensemble lacks astrophysical and instrumental impostors.
