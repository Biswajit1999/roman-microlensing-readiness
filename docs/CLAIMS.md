# Claims Ledger

Every scientific or quantitative claim made in this repository's README and
documentation must trace to one of: (a) a citation to external literature,
(b) a test in this repository's test suite, or (c) a versioned output file
in `results/`. Claims without one of these are bugs in the documentation and
should be filed as an issue.
